# 🚗 Autos Certificados Tlalpan — Demo Comercial

Demo personalizada e independiente para el lote **Autos Certificados Tlalpan S.A. de C.V.**, socio oficial de ANCA en la Ciudad de México.

## Stack Tecnológico
- **Framework:** Next.js 16 (App Router) + React 19 + TypeScript
- **Estilos:** Tailwind CSS v4 con paleta extraída del negocio (`#F8CF41`, `#2A2C32`, `#1C1E23`)
- **Iconos:** Lucide React + SVGs nativos optimizados
- **Datos:** Mock Data local estructurada en `src/data/inventory.ts`
- **Integración comercial:** WhatsApp direct con prellenado dinámico de cotizaciones y simulador

## Secciones Implementadas
1. **Top Bar:** Horarios, ubicación física en Calz. de Tlalpan 2247 Bis, teléfonos y redes sociales.
2. **Navbar:** Logo vectorial de alta resolución y accesos rápidos.
3. **Hero (Ref 2):** Titular persuasivo, métricas de confianza, llamada a la acción y respaldo ANCA.
4. **Buscador Multicriterio:** Filtro flotante por modelo, carrocería, marca y rango de precio en MXN.
5. **Cintillo de Marcas:** Accesos directos a las marcas más solicitadas.
6. **Catálogo de Unidades (Ref 3):** 9 vehículos variados con especificaciones completas y selector por pestañas.
7. **Ficha Técnica Modal:** Galería de imágenes, equipamiento y especificaciones legales de cada auto.
8. **Vender Mi Auto:** Cotizador exprés para compra o toma a cuenta con estilo plano y sobrio.
9. **Por Qué Elegirnos:** Pilares de garantía por escrito, dictamen legal y certificación ANCA.
10. **Simulador de Financiamiento Interactivo:** Selector de enganche (20%-70%) y plazo (12-60 meses) con cálculo en vivo y salida a WhatsApp.
11. **Testimonios de Clientes:** Opiniones verificadas con badge de 4.9 estrellas en Google.
12. **Sucursal & Citas de Manejo:** Formulario de reserva, mapa de Google Maps y horarios de atención.
13. **Footer:** Logotipo, navegación, categorías de autos y aviso legal de socio ANCA.

## Comandos
```bash
npm run dev    # Iniciar servidor local de desarrollo
npm run build  # Compilar para producción
```
